# 久谦·行业品类品牌趋势看板V2.0

正式入口：<https://yichu-zql.github.io/jq-industry-scan/>

面向行业研究的静态看板。七个入口：行业概览、类目大盘、类目价格带、竞品格局、品牌深挖、口径与数据、行业趋势速览。支持久谦一级／二级／三级分级多选、平台多选、年累计／近12个月／单月／历年／自定义月份。

## 业务口径

- 金额均为 **GMV（退后）**，使用久谦 `gmv`。沿用已有行业竞品看板口径；源表没有单列退款字段。
- 类目使用事实表自带的 `jq_cate1/2/3`，稳定ID来自完整路径的 SHA256 前16位；不通过存在多对多歧义的映射表关联扩张记录。
- 行业表先按大小写敏感的完整业务键检查冲突，再聚合。数据库默认不区分大小写，`PPR管件` 与 `ppr管件` 不能被误当成同一条重复记录删除。
- 持续下滑：最近三个完整年度同比均＜0；持续中低速增长：均＞0且三年CAGR＜20%；持续高速增长：均＞0且CAGR≥20%；其余可判定情况归“持平或波动增长/回落”。
- 判断三个年度同比需要四个完整年度。历史不足、缺月或基期非正时不强行分类。
- 增长品类：久谦三级类目，最近完整12个月GMV（退后）≥1亿元，且连续三个完整年度均增长，或三个年度中至少一年同比严格＞50%。
- 矩阵规模按截止月向前12个月，历史增长按截至截止月的最近完整年度；不把单月或年累计金额当成年规模。
- CR5和TOP3使用当期品牌排名；未知品牌计入分母、不参加排名。品牌份额与CR5使用同源品牌表总额（含未识别品牌）作为分母；跨表覆盖差异单独披露，不再隐藏份额。
- 缺失不是零。金额可显示已入库合计，但不完整范围的同比、份额变化不计算。件均价先汇总再相除。
- 价格带使用商品原始 `asp`，左闭右开；缺失和非正价格单独保留。当前采用统一绝对价格档，便于多类目比较；不同类目价位不能直接解读为同等产品档次。
- 品牌名称仅做 Unicode NFKC、首尾空白及大小写归一，不做无依据的品牌归属或系列推断。

## 更新入口

源库只执行 SELECT 和会话级只读设置，不写源表。表上没有可用索引，首次和后续完整刷新采用全量快照，按一级行业分批；不宣称已实现最近三个月增量。

凭据经标准输入传给 Python。Windows无人值守更新所需配置保存在被忽略的 `.private/connection.xml`，密码必须使用当前Windows用户DPAPI加密；不提交、不上传、不打印。可通过 `JQ_DEPENDENCIES` 指向本地PyMySQL安装目录。缓存可由 `JQ_CACHE_DIR` 指定，生产刷新为每次独立候选目录。

```powershell
# 完整候选检查；不推送
pwsh -NoProfile -File scripts/refresh.ps1 -Force
# 检查源变化，有变更才刷新、校验、发布和线上复验
pwsh -NoProfile -File scripts/refresh.ps1 -Publish
```

源变化签名使用各表最大入库时间与行数；若源库原地修订且不更新入库时间、行数，需使用 `-Force` 强制刷新。失败保留线上上一成功发布；运行状态写 `.private/last-run.json`，失败返回非零退出码。不在失败时推进源签名或修改线上成功时间。自动调度的实际启用状态以页面和交付记录为准；脚本存在不等于定时任务已运行。

定时任务配置：`pwsh -NoProfile -File scripts/register-refresh.ps1`，本机北京时间每日17:30，次日起生效，要求当前用户登录和联网；禁用时加 `-Disable`。源签名在提取前后比对，提取期间源数据变化则拒绝发布。失败记录仅在本机，未配置外部消息通知。若推送失败留下未发布本地提交，定时任务会停止并要求维护时核对，不擅自推送其他改动。

“历年”模式提供起止年份选择，汇总按所选年份合计，类目大盘增加年度明细并默认年度趋势。最新年份只到数据截止月份；类目价格带迁移按所选各年独立展示。其他快捷时段的类目大盘趋势也使用实际选定月份范围，不再固定展示36个月。

## V2.2.4：竞品价格带快速切换

`python scripts/build_competition.py` 从已发布的商品品牌月度数据生成一级类目 × 价格带的精确分片，保留全部品牌、月份及平台，不拼接截断的TOP榜。刷新流程在发布前构建分片，`manifest.competitionCubes` 绑定源版本。完整一级类目按选中价格带加载，部分子类目回退到原始精确分片。

独立竞品线程复用进行中的下载、已解码的月份/平台索引及最近筛选结果。140毫秒合并连续勾选，保留筛选控件；新选择使旧计算失效，不中断可复用的下载。排名、当期/同期份额、月度曲线、主力价格带及历年数据从同一筛选计算完成后统一替换。更新中或失败时保留明确标注的旧结果并禁止导出，重试不丢失选择。CSV仍为原始元数值，范围与已完成的当前结果一致。

## V2.3.0：一页纸概览

行业概览的“一页纸概览”使用独立弹窗与局部筛选；默认继承已选类目、时间和平台，跨行业时先选定一个一级行业。支持一级/二级/三级、自定义月份、近12个月、年累计和年度，价格带多选，手动生成避免反复触发重计算。顶部三段小结依次说明市场判断、机会落点与进入条件；下方为趋势/结构、价格带/品牌及最多3个机会候选。叶级结构自动切换平台，单价格带展示其占全价位份额。

报告全部金额、品牌份额和价格带使用已发布商品表同源记录，和其他页面的行业表/品牌表规模可能不同，不混用分母。同比仅比较共同三级类目-月份-平台-价格带记录，缺失不补零。机会候选要求观察≥3个月、市场份额≥1%、当前可比金额覆盖≥80%、同比≥10%且领先基准市场≥5pp（单一三级类目比较所属二级，其余比较所选范围）、可比增量为正，按增量排序；这是研究筛选而非盈利保证。价格带以正增长的可比增量优先，否则仅标主销价位。SKU未接入：只展示已有品牌参照，不创建虚构商品卡、型号或卖点；口径集中在页脚和可展开说明。

`build_report.py` 将每个一级行业的原始价格带记录按三级类目保留后压缩为单文件，绑定数据版本。按需导入报告模块，独立Worker缓存数据与最近结果，变更范围立即废弃旧请求并禁用导出。Canvas绘制同一不可变快照用于预览、PNG和单页A4 PDF（图片版），不依赖外部AI或截图CDN。导出不包含界面控件或过期结果。报告数据管道已纳入刷新和发布校验。

## V2.4.0：行业趋势速览与可编辑图表

在“口径与数据”后新增独立页签。局部筛选支持跨行业三级类目组合（按ID去重）、年度范围、末年截止月份、平台及细分层级，点击生成后按同一筛选快照分阶段展示市场规模和品牌证据。完整年度与末年累计独立标注；最新累计与上年相同月份比较。首个展示年作为基期不画同比。细分类目默认TOP6＋其他，分组和颜色在各年度一致，其余类目仍计入总额。

`lib/trend-model.js` 管理纯计算与格式规则；`trend-worker.js` 负责后台聚合、精确品牌分片规划与缓存；`trend-chart.js` 生成可编辑SVG及对应数据表；`trend-export.js` 为浏览器端OOXML导出适配器；`trend-view.js` 负责局部状态与交互。新图表应复用序列模型，计算模块不得返回已格式化的数值。模块按需导入，不增加原首页的计算或下载。离开页签或更改条件即废弃旧计算，旧结果下载按钮禁用；下载只使用已完成的范围。
